`Secure Medical Data Gateway (SMDG)`

Self-hosted сервис для безопасной передачи медицинских файлов между врачами и клиниками с шифрованием, временными ссылками и аудит-логами.

* Загрузка файлов через веб-интерфейс
* Автоматическое шифрование файлов на сервере
* Генерация временной ссылки для скачивания
* Ограничение времени доступа (TTL)
* Одноразовый или ограниченный доступ по ссылке
* Расшифровка только при скачивании
* Аудит-лог:

  * загрузка
  * скачивание
  * истечение срока
* Self-hosted развёртывание через Docker
