`Secure Medical Data Gateway (SMDG)`

Self-hosted сервис для безопасной передачи медицинских файлов между врачами и клиниками с шифрованием, временными ссылками и аудит-логами c интеграцией ИИ.

🚀 Основные функции MVP (Версия 1.0)

1.Безопасная загрузка и обмен файлами

✅ Базовые требования:
- Загрузка перетаскиванием (макс. 500MB/файл)
- Поддержка медицинских форматов: DICOM, PDF, JPG, PNG, DOCX
- Шифрование файлов на сервере (AES-256)
- Ссылки с ограниченным сроком действия (1-30 дней)
- Пароль для доступа (опционально)
- Уведомление по email о новом файле
========================================================================

2.ИИ-анализ файлов (автоматический)

✅ Три типа анализа в зависимости от файла:

📄 PDF-выписки/анализы:
- Извлечение диагноза, рекомендаций, назначений
- Предложение кодов МКБ-10
- Выделение ключевых показателей (лабораторные, давление и т.д.)
- Авто-аннотация важных разделов

🖼️ Медицинские изображения (DICOM/рентген):
- Предварительное описание находок
- Определение типа исследования (КТ, МРТ, УЗИ)
- Извлечение метаданных DICOM
- Конвертация DICOM → PNG для быстрого просмотра

🎤 Аудио диктовки врачей (опционально):
- Транскрипция речи в текст
- Выделение медицинских терминов
- Структурирование по разделам
==========================================================================

3. Система контроля доступа

✅ Ролевая модель:
- Врач (может видеть только своих пациентов)
- Заведующий отделением (видит всех в отделении)
- Администратор клиники (полный доступ)
- Лаборант (только загрузка, без просмотра истории)

✅ Аутентификация:
- Email/пароль + 2FA (SMS/приложение)
- Сессии с таймаутом 30 минут
- Запрет параллельных сессий
=========================================================================
4. Логирование и аудит (по ФЗ-152)

✅ Обязательное логирование:
- Кто (user_id) → Что (action) → Когда (timestamp) → Кого (patient_id)
- Все скачивания, загрузки, просмотры
- Попытки несанкционированного доступа
- Экспорт логов для проверок Роскомнадзора

✅ Авто-отчеты:
- Еженедельный отчет по активности
- Отчет по доступу к данным пациента
- Отчет для проверок (готовность 1 клик)

🛠️ Технические требования MVP

# Минимальный стек:
- FastAPI (основной фреймворк)
- PostgreSQL (данные + аудит)
- Redis (кеш + сессии)
- MinIO/S3 (хранение файлов)
- Celery (фоновые задачи ИИ)
- Docker (контейнеризация)

# ИИ-сервисы MVP:
- OpenAI API (GPT-4 для анализа текстов)
- Yandex SpeechKit (транскрипция аудио)
- Custom DICOM parser (pydicom)
- Резерв: локальные модели на transformers

Фронтенд (React/Vue)

✅ Основные компоненты:
- Дашборд с последними файлами
- Форма загрузки (drag & drop)
- Просмотрщик файлов (PDF, изображения)
- Чат к файлу (комментарии врачей)
- Настройки доступа

✅ Мобильная версия:
- Адаптивный дизайн
- PWA для установки на смартфон
- Уведомления в реальном времени

Безопасность

✅ Соответствие ФЗ-152:
- Все данные в РФ (хостинг Selectel/Yandex Cloud)
- Шифрование при передаче (TLS 1.3)
- Шифрование при хранении (AES-256)
- Детальное логирование
- Резервные копии ежедневно

✅ Дополнительно:
- Защита от DDoS (Cloudflare)
- WAF (Web Application Firewall)
- Регулярные пентесты
