# FAQ

Частые вопросы по SMDG.

## Общие

### Что такое SMDG?

Secure Medical Data Gateway — платформа для безопасной передачи медицинских файлов с шифрованием age, временными ссылками и DICOM Viewer.

### Нужен ли интернет?

Для self-hosted инстанса интернет нужен только для TLS, обновлений и внешних webhook. Данные обрабатываются на вашем сервере.

### Есть ли демо?

Да: **https://fileguardian.info** (профиль `demo`, данные сбрасываются раз в 24 ч).

## Безопасность

### Как шифруются файлы?

Алгоритм **age** (X25519). Ключ хранится в `keys/age.key` (Docker secret в prod).

### Поддерживается ли 2FA?

Да, TOTP (Google Authenticator, Authy). В профиле `russia` может быть обязательной.

### Где хранится аудит?

`audit_logs/` — JSON по дням + CSV. Экспорт для админа: Excel/PDF/CSV.

## Файлы и ссылки

### Какой максимальный размер файла?

По умолчанию 600 МБ (`MAX_UPLOAD_SIZE_MB`). В demo — меньше.

### Можно ли отозвать ссылку?

Да, владелец или admin может удалить ссылку досрочно.

## DICOM

### Нужен ли клиентский DICOM viewer?

Нет, рендеринг на сервере → PNG в браузере.

### Поддерживается ли multi-frame CT?

Да, режим **Cine** для последовательностей кадров.

## Деплой

### Какой профиль выбрать для клиники в РФ?

`DEPLOYMENT_TYPE=russia` — локальное хранилище, ФЗ-152-ориентированные настройки.

### Можно ли использовать S3?

Да, профили `intl` и `saas`, или `S3_ENABLED=true` в `.env`.
