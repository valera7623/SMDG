Добрый день!

Меня зовут Валерий Попов. Я разработчик SMDG (Secure Medical Data Gateway) — self-hosted шлюза для безопасной передачи медицинских файлов и просмотра DICOM в браузере. Обращаюсь по поводу возможного пилота для одного из центров сети Ай-клиник.

**Задача, которую закрываем:** обмен исследованиями между филиалами, направляющими врачами и пациентами — без мессенджеров, публичных дисков и передачи расшифрованных файлов «как есть». Файлы шифруются на сервере (age), передаются одноразовыми ссылками с TTL, все действия фиксируются в аудите с экспортом для службы ИБ.

**Почему это может быть актуально для сети с большим потоком МРТ/КТ:**
- данные остаются в контуре клиники или VPS/ЦОД в РФ (профиль развёртывания `russia`: локальное хранилище, обязательная 2FA, журнал до 3 лет);
- встроенный DICOM Viewer — просмотр в браузере без отдачи расшифрованного файла клиенту;
- SMDG не заменяет МИС и PACS — это отдельный шлюз передачи; интеграция с вашими системами возможна через API и webhooks.

**Попробовать без созвона:** https://fileguardian.info (публичный инстанс, профиль `demo`).

**Пилот:** 5 рабочих дней, от 150 000 ₽ (один сервер, один центр, до 50 пользователей — точная смета после короткого созвона). Входит развёртывание, настройка HTTPS, обучение администратора, пакет документов для ИБ. Исходный код — MIT: https://github.com/valera7623/SMDG

Публичное демо уже доступно (профиль `demo`): **https://fileguardian.info** — можно посмотреть загрузку, ссылки и DICOM без созвона. Если формат подходит — предлагаю короткий созвон (20–30 мин) или сразу обсудим пилот на одной площадке (например, Тимуровская или Крестовский) как ограниченный промышленный контур; направлю одностраничное КП.

Меня зовут Валерий Попов. Разрабатываю SMDG — self-hosted шлюз для безопасной передачи медицинских файлов и DICOM. Обратил внимание на ваш кейс по приведению частной клиники в соответствие с 152-ФЗ: после организационных мер и документов у заказчиков часто остаётся практический вопрос — **как технически передавать снимки и заключения**, не нарушая политики ИБ.

Предлагаю рассмотреть SMDG как **рекомендуемое техническое решение** в ваших проектах для клиник и диагностических центров.

**Кратко о продукте:**
- развёртывание в контуре заказчика (VPS/сервер в РФ), профиль `russia`: локальное хранилище, обязательная 2FA, хранение журнала аудита до 3 лет;
- шифрование файлов (age), одноразовые ссылки с TTL, автоочистка;
- DICOM Viewer в браузере;
- экспорт аудита для проверок и внутреннего контроля;
- исходный код MIT — ваша команда и ИБ клиента могут провести review без закрытого ПО.

**Для вашей модели услуг:**  
вы проводите аудит и приводите процессы к 152-ФЗ → при выявлении рисков обмена файлами (мессенджеры, облака, «личные диски») рекомендуете пилот SMDG → внедрение выполняю я по фиксированному пакету (**5 рабочих дней, от 150 000 ₽**), вы не раздуваете scope ИБ-проекта собственной разработкой.
