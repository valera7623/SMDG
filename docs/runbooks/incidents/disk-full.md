# Инцидент: Заполнение диска

## Симптомы

- свободное место < 10%
- ошибки записи в логи/хранилище/БД

## Диагностика

```bash
df -h
du -sh /var/lib/docker/* 2>/dev/null | sort -h
du -sh audit_logs encrypted uploads backups 2>/dev/null
docker system df
```

## Восстановление

1. Очистить старые логи и временные файлы.
2. Очистить неиспользуемые docker-образы/тома после проверки.
3. Перенести/архивировать старые бэкапы.
4. Увеличить диск или настроить ротацию.
