# Эскалация

## Уровни

| Уровень | Симптомы | SLA реакции |
|--------|----------|-------------|
| P1 | Полная недоступность API, риск потери данных | Немедленно |
| P2 | Частичная недоступность, высокий error rate | До 1 часа |
| P3 | Деградация без остановки сервиса | В течение рабочего дня |
| P4 | Минорные проблемы | Планово |

## Кого звать

- L1 Support: `@support-team`
- L2 DevOps: `@devops-team`
- L3 Engineering Lead: `@engineering-lead`
- Security: `security@smdg.local`

## Минимальный пакет при эскалации

1. Краткое описание симптомов и impact
2. Время начала и текущий статус
3. Выполненные шаги и результаты
4. Логи и метрики (артефакты из debug guide)
